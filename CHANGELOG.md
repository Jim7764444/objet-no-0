# Changelog

All notable changes to Objet N°0 are documented here.

## [Unreleased]

### Added

- Playable six-file classification loop with three rulings, evidence inspection,
  a stability meter, and immediate decision feedback.
- Four upgrades, four unlockable doctrines, persistent archive progress, and a
  best-score record.
- Optional two-file annex with a clear score penalty and service-ending failure.
- Original responsive desk UI and artifact illustrations drawn from runtime
  primitives; no external art assets or copied game content.
- Editor validation that creates or repairs the opening scene, synchronizes
  Unity's bundle version from `VERSION`, and verifies the classification rules.
